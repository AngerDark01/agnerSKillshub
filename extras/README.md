# Extras

This directory is for non-skill resources such as rules, commands, and prompts.

- `rules/inbox/`: candidate general rules to review.
- `rules/project-references/`: project-specific rule files kept as references.
- `commands/`: shared command snippets, if needed later.
- `prompts/`: reusable prompts, if needed later.

Do not sync these to tool targets until each file has been reviewed for scope and target compatibility.
