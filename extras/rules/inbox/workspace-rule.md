- 必须输出所有结论：每个互斥小组的唯一符合项 + 所有非互斥独立结论（e.g., "部分电流数据正常" 和 "部分电流数据异常" 可共存）。
- 计算总结论数：互斥小组数（从互斥列表长度） + 非互斥独立结论数（从判断依据识别，如不在任何互斥组的结论）。
- 示例：互斥小组13个 + 独立2个 = 15条结论。
- 互斥组在同一条结论中分析（e.g., "对于['正常', '异常']组，选择正常因为..."），禁止分开。

4. 数据引用和分析规范：**
- 分析依据必须详细：数据来源、数值细节、工具结果、推理步骤。
- 针对需计算的部分（如范围、大小、变化率），必须引用工具结果进行推理。
- 由于产品端的要求，我们禁止在最终结论中显示“根据工具调用结果”或者实际工具名称的情况，需要在结论中隐藏调用工具的事实。
- 输出结论必须依据工具调用结果，（这与上一条并不冲突，实际是我们调用工具作为判断依据，但是不会说明我们调用了工具）

5. 标准化结论模板（每条结论必须使用）：
- X. [结论标题]：（e.g., SF6压力异常）
  - 分析依据：[详细解释：数据细节（包括设备的名称，检查点（即设备名成之后的编号），以及具体查询出来的结果：比如“检查了首端保护电流的具体值：5611ACFA-首端保护电流Iha: 247.84 A"） + 对数据进行分析+ 为什么选择此项而非互斥其他 + 推理步骤]
  - 判断结果：符合/不符合【此处存在互斥列表中的项必须只输出符合项，非互斥列表中的独立项，才可以有不符合】
  - 结论：[结论内容，与标题一致]

**注意事项：**
- 确保每个互斥组只输出一符合项，避免互斥选项共存。
- 分析完整：包含选择/排除理由。
- 独立结论：识别不在互斥列表的，如"部分电流数据正常/异常"（可共存）。
- 总体评估：总结所有结论，形成设备状态概述。
