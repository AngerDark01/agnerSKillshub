# 专业设计分析框架

> 这是第三阶段的完整分析清单。对照截图和采集到的 token 数据，逐维度填写。
> 每个维度必须有**具体数值或可引用描述**支撑，禁止使用「简洁」「现代」「大气」等空泛形容词。

---

## 维度一：视觉基调（Visual Tone）

这是最先被感知的层面，决定用户对产品的第一印象。

**1.1 明暗基调**
- 主体背景是深色还是浅色？背景具体色值是什么？
- 是否有主题切换（dark/light mode）？
- 深色方案中背景是纯黑还是带色相的暗色（如 Linear 的 `#1a1a2e` 带蓝调）？

**1.2 色彩情绪**
- 主色调属于哪个色系（冷/暖/中性）？
- 产品使用几种主要颜色？主色 / 辅助色 / 强调色分别是什么？
- 色彩饱和度倾向（高饱和活力 vs 低饱和沉稳）？
- 渐变的使用：是否有渐变？线性还是径向？渐变色值？

**1.3 信息密度**
- 首屏信息量：稀疏（大留白为主）/ 适中 / 密集（信息驱动）
- 内容区最大宽度约为多少 px？
- 段落间距、组件间距的大致感受（宽松 / 紧凑）

---

## 维度二：排版系统（Typography System）

排版是设计语言的「声音」。

**2.1 字体选用**
- Display 字体（大标题用字）：字体名、风格特征（几何/人文/衬线）
- Body 字体（正文用字）：字体名、是否与 Display 不同
- 是否使用系统字体栈？还是自定义 Web Font？
- 字体组合的整体气质：严肃/友好/技术/艺术

**2.2 字阶与节奏**
- 最大标题字号约为多少？（H1）
- 正文字号是多少？（通常 14~16px）
- 字阶跨度：标题到正文的比例差异是否明显？
- 行高（line-height）倾向：紧凑（1.2~1.4）/ 舒展（1.6~1.8）

**2.3 字重运用**
- 是否大量使用粗字重（700/800/900）作为视觉锚点？
- 正文字重（400/500）？
- 是否有大面积纤细字（300）用于装饰？

**2.4 字间距**
- 标题是否有负字间距（letter-spacing: -0.02em 之类）？这是高级感的常见手法
- 标签/按钮文字是否有正字间距营造规整感？

---

## 维度三：空间与布局（Space & Layout）

**3.1 间距系统**
- 基础间距单位是多少？（通常是 4px 或 8px）
- 组件内部 padding 规律？（如 Linear 严格遵守 8px 倍数）
- 大区块之间的 section gap？

**3.2 网格与对齐**
- 内容最大宽度（max-width）？
- 是否使用传统 12 列网格还是 CSS Grid 自由布局？
- 文字左对齐 / 居中对齐的使用场景？

**3.3 圆角策略**
- 按钮圆角：sharp（0~2px）/ moderate（4~8px）/ round（12px+）/ pill（full）
- 卡片圆角与按钮是否一致？
- 圆角是否有层级：大容器用大圆角，小元素用小圆角？

---

## 维度四：层次与深度（Depth & Layering）

**4.1 阴影系统**
- 是否使用阴影？阴影风格：现实感（多层叠加）/ 扁平（无阴影）/ 极微妙（只有 1~2px）
- 卡片的 box-shadow 具体值？
- 是否用阴影来表达 z 轴层级？

**4.2 边框与分割线**
- 分割线使用频率：多（信息密集型）/ 少（卡片式布局）
- 边框颜色透明度：`rgba(255,255,255,0.08)` 这类极低透明度细线是高端感的典型手法
- 是否用 `border` 还是 `outline` 或 `box-shadow` 来模拟边框？

**4.3 背景层次**
- 是否有多层背景（main bg / sidebar bg / card bg）颜色微差？
- 是否使用 `backdrop-filter: blur()` 玻璃效果？
- 是否有 noise texture / grain 叠加增加质感？

---

## 维度五：动效与交互（Motion & Interaction）

**5.1 过渡时长**
- hover 状态切换时长约为多少 ms？（100ms 活泼 / 200ms 标准 / 300ms+ 优雅）
- 页面加载动画时长？

**5.2 缓动函数**
- 使用 ease / ease-in-out / 自定义 cubic-bezier？
- 弹性动效（spring）还是线性？

**5.3 交互反馈**
- hover 时元素如何变化：颜色变化 / 位移 / 缩放 / 发光？
- 按钮 active 状态是否有压下感？
- 是否有 skeleton loading / shimmer 效果？

---

## 维度六：组件设计语言（Component Language）

**6.1 按钮**
- Primary 按钮：背景色、文字色、圆角、padding、是否有边框
- Secondary / Ghost 按钮：如何与 Primary 区分
- 按钮是否有 icon + text 组合

**6.2 输入框**
- 边框风格：有框线 / 底线 / 无框（填充背景）
- focus 状态：边框颜色变化 / 光晕效果
- placeholder 颜色透明度？

**6.3 卡片 / 面板**
- 卡片背景与页面背景的色差程度？
- 卡片是否有 hover 状态（边框高亮 / 背景变化）？

**6.4 导航**
- 顶栏高度约为多少？是否有磨砂/透明效果？
- active 状态如何标识（下划线 / 背景块 / 颜色变化）？
- 侧边栏是否存在？宽度约为多少？

---

## 维度七：设计哲学提炼（Design Philosophy）

> 这是最难的一步，也是最有价值的。基于以上六个维度，提炼出这个产品的设计信念。

回答以下问题（每条用 1~2 句有具体细节的描述）：

1. **这个产品在美学上「押注」在哪里？** 它的核心赌注是极致克制、还是强烈视觉冲击、还是功能优先？

2. **它的主要设计矛盾是什么？** 例：Linear 的矛盾是「信息密度 vs 克制美感」，它通过极细的边框和小字号在高密度下依然保持呼吸感。

3. **它用什么手法制造「高级感」？** 是负字间距？是极低透明度细边框？是 noise texture？还是别的？

4. **它在哪里「违反直觉」？** 优秀的设计往往有一处反常规的选择，找到它。

5. **如果用一段话描述这套设计，让另一个 AI 能复现出 70% 的神韵，怎么写？**（这段话最重要，直接写进 design-dna.md 的「设计约束语言」区）
