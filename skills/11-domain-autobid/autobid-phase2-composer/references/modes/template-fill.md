# Mode: template_fill

## 适用场景

- 招标文件原文中已有成熟模板。
- 章节既包含模板外壳，也需要填写具体正文。
- 模板本身对最终提交仍有较强约束。

常见章节：`投标保证金承诺函`、`授权委托书`、`承诺函`。

## 必读工具

- 模板定位与切片：`../../../autobid-office-tools/references/docx-inspect.md`
- 拆分和回拼：`../../../autobid-office-tools/references/docx-split.md`
- 文本填写：`../../../autobid-office-tools/references/docx-write.md`

## 标准动作

1. 从招标文件抽原始模板。
2. 判断模板中的标题角色和开头说明角色。
3. 删除提示类标题，保留正式标题和应提交的开头说明。
4. 按 `输出章节模板` 同步处理父级重编号。
5. 区分本章哪些是图片主体，哪些是文本或表格正文。
6. 图片主体优先直接复用关系和媒体。
7. 文本、表格、项目字段按招标文件格式要求逐项填写。

## 标题规则

模板类章节通常会同时出现：

- 章节编号标题。
- `XX格式 / XX模板 / 示例` 提示标题。
- 居中的正式文书标题。

默认处理：

- 编号标题保留。
- 正式文书标题保留。
- 属于正式内容的开头说明、编制说明、适用范围保留。
- `XX格式 / XX模板 / 示例` 提示标题删除。

## 特殊规则

- 删除提示标题时，不能误删真正的文书标题。
- 模板不能抽出来就整章直套；标题、开头、正文文本、表格内容都要重新核对。
- 如果模板大部分由图片或扫描件拼接出来，优先直接拼接图片与关系文件，不重做图片区。
- 图片之外的文本、表格、项目字段和导语必须检查是否符合当前招标文件要求。
- 用户要求留空的签字、盖章、日期行保持原样。
- 授权类和承诺类模板，只自动填项目级公开字段，不自动填个人敏感信息。

## Done 条件

- 提示标题已处理，正式标题未误删。
- 应填写的项目字段已填写或明确 pending。
- 敏感签字、盖章、日期、个人信息未臆造。
- 输出章节已通过最小 DOCX 检查。
